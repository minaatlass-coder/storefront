# Photos de marque (accueil)

Déposez vos fichiers **ici** (`public/brand/`) avec **exactement** ces noms :

| Fichier | Où ça s’affiche |
|---------|------------------|
| `home-hero.jpg` | Grande photo à droite en haut de l’accueil |
| `home-approach.jpg` | Photo dans la section « Notre approche » |

## Format conseillé

- **Ratio** : 5:4 (paysage) ou 4:5 (portrait)
- **Taille min.** : 1200 px de large
- **Format** : JPG ou WebP

## Important

1. Le nom du fichier doit être **identique** (minuscules, tirets).
2. Pas besoin de modifier le code : remplacez le fichier et redéployez (ou rechargez en local).
3. Si le fichier est absent ou invalide, un fond beige s’affiche à la place.

Les chemins sont définis dans `src/data/site.ts` → `images.homeHero` et `images.homeApproach`.
